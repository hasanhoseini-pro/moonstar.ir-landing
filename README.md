# استودیو نرم‌افزاری ماه و ستاره | MoonStar Studio
وب‌سایت رسمی و صفحات فرود (Landing Pages) استودیو نرم‌افزاری ماه و ستاره.

## محصولات استودیو:
1. **سامانه مدیریت خانه بازی همبازی:**
   - سامانه جامع مدیریت هوشمند خانه‌های بازی، مهدکودک‌ها و شهربازی‌های سرپوشیده.
   - ثبت حضور ثانیه‌ای، محاسبه خودکار تعرفه زمانی، تقویم رزرو جشن تولد، سیستم بوفه و امکانات VIP، ارسال پیامک خودکار به والدین و گزارشات مالی دقیق.
   - [دریافت همبازی از کافه بازار](https://cafebazaar.ir/app/ir.moonstarstudio.hambazi)
   - [دریافت همبازی از مایکت](https://myket.ir/app/ir.moonstarstudio.hambazi)

2. **اپلیکیشن وام خانگی دست به دست:**
   - سامانه هوشمند و عادلانه قرعه‌کشی و مدیریت وام‌های خانگی و دورهمی.
   - گردونه آنلاین قرعه‌کشی، محاسبه خودکار اقساط، حالت محرمانه، پنل مجزای مدیر و اعضا.
   - [دریافت دست به دست از کافه بازار](https://cafebazaar.ir/app/ir.techninja.dastbedast)
   - [دریافت دست به دست از مایکت](https://myket.ir/app/ir.techninja.dastbedast)

## ساختار پوشه‌بندی و معماری فایل‌ها:
```
├── CNAME                   # دامنه اختصاصی moonstarstudio.ir
├── index.html              # لندینگ پیج اصلی استودیو ماه و ستاره
├── hambazi.html            # صفحه اختصاصی معرفی و دانلود همبازی
├── dastbedast.html         # صفحه اختصاصی معرفی و دانلود دست به دست
├── css/
│   └── style.css           # دیزاین سیستم، متغیرها و استایل‌های واکنش‌گرا
├── js/
│   └── main.js             # منطق تغییر تم، منوی موبایل و تعاملات
└── assets/                 # دارایی‌های چندرسانه‌ای به تفکیک پروژه
    ├── studio/             # لوگو و هویت بصری استودیو ماه و ستاره
    ├── hambazi/            # آیکون و اسکرین‌شات‌های سامانه همبازی
    └── dastbedast/         # آیکون و تصاویر محیط اپلیکیشن دست به دست
```
